# Freddy Servicio Técnico — logo assets

All type is converted to outlines. No font files needed, nothing to install, and the
signwriter can cut the SVG directly.

## Which file to use

| Use | File |
|---|---|
| Website header, invoices, quotes | `svg/freddy-logo-primary.svg` |
| Anything printed in one colour | `svg/freddy-logo-black.svg` |
| Van livery, dark backgrounds, polo shirts | `svg/freddy-logo-reversed.svg` |
| Google Business Profile logo | `png/freddy-logo-avatar-250.png` |
| Social avatars, WhatsApp Business | `png/freddy-logo-avatar.png` (512px) |
| Square placements needing the full name | `svg/freddy-logo-square.svg` |

**Send the signwriter the SVG, not the PNG.** Vinyl cutters need vector.

## Why there are two square versions

`square` includes "SERVICIO TÉCNICO"; `avatar` drops it. Below roughly 300px the
subline stops being legible and turns into a grey smear, so the avatar version carries
the wordmark and rule alone. Use `avatar` anywhere the logo appears small or inside a
circular crop.

## Colours

| | Hex | Notes |
|---|---|---|
| Ink | `#1A1A1A` | Not pure black — prints and screens better |
| Orange | `#E8590C` | The only accent. Never used for type. |
| Paper | `#FFFFFF` | |

For vinyl, take **RAL 2004** or **Pantone 165 C** as the nearest orange match and ask
the signwriter to confirm against a physical swatch before cutting.

## Typefaces

- **FREDDY** — Archivo Black (SIL Open Font License, free for commercial use)
- **SERVICIO TÉCNICO** — Oswald SemiBold, letterspaced 120/1000

Both from Google Fonts. Use the same pair on the website for consistency.

## Rules

- **Clear space:** keep a margin all round equal to the cap height of the F. Nothing
  intrudes into it.
- **Minimum size:** 25mm wide in print for the full lockup. Below that, use the avatar
  version.
- **Never** stretch, recolour, add a shadow, outline the type, or place the primary
  version on a mid-tone background — use the reversed version instead.
- **The orange rule always spans the full width of the wordmark.** It's the one
  structural element holding the lockup together.

## Deliberately no icon

The mark is typographic so it survives the move into climatización without a redesign,
and so it reproduces cleanly in embroidery, vinyl and at avatar size. A literal
appliance illustration would have done none of those things.
